# 票智 · 智能报销工作台 Demo

这是一个无需安装依赖的单页演示原型，覆盖三项核心能力：

- 票据采集：手机拍照、相册上传、PDF/电子票、邮箱收票入口
- 智能识别：上传图片后调用浏览器端 Tesseract OCR，识别发票号码、日期、销售方和金额，并回填到表单
- 智能审核：模拟验真、查重、报销标准、预算和超时限检查

## 本地预览

直接双击 `index.html` 即可打开。首次进行 OCR 时需要联网加载中文识别模型和 PDF 页面转换组件；也可以把整个 `outputs` 文件夹放到任意静态网站托管平台。PDF 会自动把首页转成图片后进行 OCR。

## 发布到 GitHub Pages

1. 在 GitHub 新建一个仓库。
2. 上传 `index.html`（README 可选）。
3. 进入仓库的 **Settings → Pages**。
4. 在 **Deploy from a branch** 中选择默认分支和 `/ (root)`，点击保存。
5. 等待几分钟，GitHub 会生成一个可公开访问的链接。

> 当前版本已支持真实图片/PDF 上传、预览和 OCR；发票验真、查重数据库、OA 接口和邮箱/微信收票仍使用演示交互。正式上线时可将这些入口接入真实服务。
